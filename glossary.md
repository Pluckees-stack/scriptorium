# Glossary

The words Scriptorium uses for things, agreed October 2026. Use these in
any new interface text. The house style is British English and sentence
case: capitalise only the first word and proper names.

| Use | Not | Notes |
|---|---|---|
| **battle** | game | A battle that's played and logged: "Play campaign battle", "End battle", "battle log". |
| **phase** | round | A stage of a *campaign* (Phase admin). Only *tournaments* have rounds. |
| **round** | | A tournament round, or a turn round in a battle ("Round 3" on the turn counter). |
| **roster** | warband, army list | A player's army in the app. Your own tab is still called **Muster list**. |
| **scenario** | mission | "Mission" survives only inside the code and database (`missions`, `mission_id`). |
| **campaign points** | Campaign Points, glory | Lower case in sentences. "Glory" is the old name. |
| **Path to Glory** | Path to glory | A proper name, so it keeps its capitals. |

## Tab names

- **Player:** Account · Muster list · Game view · Player rosters ·
  Campaign standings · Story
- **Phone bottom bar:** Account · Lists · Story · Play · Standings. Lists
  holds both Muster list and other players' rosters (a Yours / Other
  players switch); Play is Game view.
- **Admin:** Overview · Tournaments · Tournament setup · Players ·
  Scenarios · Narrative · Phases · Campaign settings · Scriptorium

When help text points at a tab, name it as it appears: "in the
Tournaments tab", "in Campaign settings".

## Deliberately left alone

- **Game view** (the tab) and **game aid** (the turn counter and spell
  helper). They're feature names, so they keep "game".
- **Game length**, **random game length**, and rules text quoted from the
  Old World rules ("the game ends…"): the rules' own wording.
- **Crushing / Major / Minor Victory**: the rules' own result names.
- **"Game on!"** when both players are ready: an idiom.
